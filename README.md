# Kitachi Studio

Landing page for Kitachi — websites and AI systems for German companies.

German-language, cream-and-sunrise brand, WebGL field (Three.js) and motion (GSAP + Lenis).

## Local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Stack

- Vite + TypeScript
- Three.js shader field in the hero
- GSAP ScrollTrigger + Lenis
- Vercel

Contact goes out as a prepared `mailto:` to `human@kitachi.de`. Legal details match kitachi.de.
